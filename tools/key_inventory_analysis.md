> 原「占格口径不一致 / 可丢弃口径不一致」两项已按作者拍板消除：10 把持久钥匙现已**全部占 1 格、全部可丢弃**。

2. **占格口径**：现已统一——10 把均占 1 格。`hasRenjiCard`、`_hasCampusKey` 原不占格，本次已补 `add: { itemCount: 1 }`（与 `hasKeyRing` 击杀获取的无条件 +1 同口径；背包满时临时越界，玩家丢一件即恢复，非软锁）。
