## 一、结论（TL;DR）

1. **mercuryLoad 是一个"只有上限判死、没有中途感知"的隐藏变量**。全库 43 处引用：**41 处写入、仅 2 处读取**（全局触发器 + 抑制剂选项门槛）。
2. **`70` 这个阈值是唯一起作用的分界线**，且是**瞬时判定**——只要跨过就立刻跳结局，不是渐进恶化。
3. **存在 1 个真 bug（P0）**：变量名叫 0–100，但**没有注册进 `_caps`**，也没有任何全局钳制。只有 5 处写入自带 `Math.min(100)`，**35 处裸 `add` 没有上限**。数值可以无限增长。→ **已修**。
4. **存在 1 个设计缺口（P1）**：设计文档《设计细节.md §三》规划的中间档体征（20–40 皮肤灰白、40–70 痛觉消失/夜视增强）**全部未实装**。玩家从 0 到 69 完全无感知，第 70 点直接死，体验是"凭空暴毙"。→ **已实装**。
5. **`结局-汞中毒尸变` 本身 0 点汞也能到**（金谊广场 B2 车库 2 处硬编码直跳），与变量无关。

## 五、玩家可见性（关键缺口）

设计文档《设计细节.md》§三 / §3.2 规划的感知通道：

| 规划内容 | 状态 |
|---|---|
| 20–40：皮肤灰白、瞳孔散大 | 🔮 未实装 |
| 40–70：痛觉消失、力量异常、夜间视力增强 | 🔮 未实装 |
| 镜子 / 水面倒影反映肤色 | 🔮 未实装（张江更衣区、理发店、新达汇卫生间均无） |
| 死亡前一次「暗灰色 + 金属光泽」描写 | ✅ 已实装（`结局-汞中毒尸变`） |

**唯一能提示玩家的文本**是金谊广场消毒处的间接说明：

> 【系统提示】伤口已消毒，感染风险降低。但已进入体内的汞不会因此消失。

（`金谊广场.js:1171`）

全库检索 `汞` 字确认：其余提及全是**世界观文档/证据链叙事**（王知筠视频、检验科记录、检测报告），**没有任何一条是"你现在体内汞到多少了"的玩家侧反馈**。

### 后果

玩家在第 70 点之前的整个过程中，**没有任何信号**提示"我正在被汞拖向死亡"。第 70 点触发时是瞬时跳转，玩家体验为**毫无预兆的暴毙**。这与项目一贯强调的「难度应来自取舍，不该来自信息不透明」（USER.md）相冲突。

## 六、发现的问题

### P0 · mercuryLoad 无上限钳制（真 bug）

**现象**：`core.js:19` 注释声明 0–100，但 `_caps`（core.js:316）未注册该键，`clampAll()` 对它无效。41 个写入点里只有 5 个自带 `Math.min(100)`，**其余 35 个是裸 `add`**，可无限累加。

**实际影响**：
- 因为触发条件是 `>= 70`，越界后**不影响死亡判定**（仍然立即死亡）。
- 真正的影响是**数据语义失真**：若后续要加中间档体征（`>= 40` 之类），或要做「服药丸 −20 能否救回来」的判定，越界值会让这些逻辑失真。药物减 20 在无上限时可能"减不动"（如 150 − 20 = 130，仍远高于 70）。
- 也会污染任何存档/统计（存档里可能出现 >100 的汞值）。

**建议修法（二选一，**平衡影响为零**，建议由波波拍板）**：
- **A（推荐）**：在 `core.js:316` 的 `_caps` 加一行 `mercuryLoad: { min: 0, max: 100 }`。一处改动，全部写入点自动受钳，与现有 `strength`/`chasedByZombies` 同款写法，零副作用。
- **B**：给 35 个裸 `add` 逐个补 `Math.min(100)`。改动面大、易漏，不推荐。

### P1 · 中间档体征未实装 → 信息不透明（设计缺口）

按设计文档，20/40 应是两个"玩家自己能感觉到不对劲"的节点。目前完全缺失，导致 70 点是凭空暴毙。

**建议**：不必全量实装，最小改动是加**一条玩家可见通道**，例如：
- 在 `_reactive.computed` 加派生变量 `mercuryTier`（0/1/2），在若干高频场景（整理整理 / 过夜）的 text 里按档位插一句身体描写；
- 或复用现有系统提示样式，在跨过 20 / 40 时各弹一次橙字提示。

> 注意：这会**实质降低难度**（给了玩家预警），属平衡决策，**需波波拍板**，本次不动手。

### 周边观察（非 bug，仅记录）

- `结局-汞中毒尸变` 有 **2 处硬编码直跳**（`金谊广场.js:668` 未戴面具深入 B2、`:1334` 未戴面具在车库）：**与 mercuryLoad 完全无关**，0 点汞也能触发。这是合理的"环境毒气即死"设计，但与变量机制同名共用同一结局节点，容易在阅读时混淆。**无需修改**，仅提示。
- 药丸选项的 `! _wearingCleanSuit` 门槛存在，但 `_wearingCleanSuit` 语义是"穿着无尘服不能进食饮水"（core.js:268）。药丸属口服，门槛合理。
- 上实南校化学实验室 `+10` 明确注释"化学气体灼伤，非丧尸咬伤，不触发感染"——即加汞但**不置 hurtByZombie**，是本库唯一"只加汞不加伤"的点，逻辑自洽。

## 九、实装记录（2026-09-23）

作者拍板三项后全部落地。三位一体：**上限钳制 + 慢性累积 + 三级隐性体征**。

### 9.1 P0 修复：`_caps` 注册（平衡影响为零）

`story/core.js` `_caps`：
```js
mercuryLoad: { min: 0, max: 100 },   // 汞负荷 0-100（死亡阈值 70，见 _globalTriggers）
```
36 处裸 `add` 从此受全局钳制；药丸 −20 不会再"减不动"。

### 9.2 慢性累积：`mercury-chronic` 规则（作者定速 **每小时 +1**）

`story/core.js` `_reactive.rules` 新增：

| 项 | 设定 |
|---|---|
| 启动条件 | `mercuryLoad > 0` —— **被咬过/喝过毒水才启动**，未暴露者永不累积 |
| 速率 | 每小时 +1（跨 N 小时一次补 N 点） |
| 台账 | `_mercuryChronicHour`（规则自维护，剧情勿改） |
| 节奏 | load=10 起 → **60 小时 ≈ 2.5 天**到 70；load=20 起 ≈ 2.1 天 |
| 与药丸的博弈 | load=20 被咬 → 48h 后 68（逼近）→ 药丸 −20 → 48 → 再 22h 到 70 |

**设计意图**：**被咬是开关，时间是放大器**。因果链完整，不会出现"没被咬却被汞杀死"的不可归因死亡。

### 9.3 三级隐性体征（不进系统提示，全部走正文）

新增派生变量（`_reactive.computed`，审计脚本自动注入，无需改脚本）：
- `mercuryTier` —— 0/1/2/3（0 / 20 / 40 / 70 分档），判定函数 `mercuryTier(load)` 在 `utils.js`
- `noPainSense` —— `mercuryTier >= 2`，痛觉消失
- `hasDimLight` —— 手电 ∨ 手机有电 ∨ 高汞夜视（弱光总闸）

| 档位 | 症状 | 落地位置 | 设计手法 |
|---|---|---|---|
| **20–40** | 皮肤灰白 | `新达汇-2F卫生间`（洗手台裂镜）、`理发店内部`（理发椅前镜子） | 只在**能照见自己**的载体触发，玩家不看镜子就发现不了 |
| **40–70** | 痛觉消失 | `金谊广场-地铁站厅-失败`、`图书馆-阅览室-徒手`、`地铁站-安检区-硬冲`、`建平-致真楼-1F-老吴杂物室`、`樱桃苑-4楼-失败` + `mercuryPainNote(vars)` 随机旁白池 | **文案反转**："火辣辣地疼" → "你先看见的是血，不是疼"；正文颜色改用灰 `#9aa0a6`，与橙色系统提示刻意区分 |
| **40–70** | 夜视增强 | `菜市场-员工通道`、`菜市场-通道迷路`、`新达汇-B1值班过道`、`新达汇-B1保安室`、`卡通尼乐园`、`新达汇-2F北走廊中`、`上实南校-3号楼-4楼-摸黑` | **正向诱惑**：黑暗中"看得清"本该是好事——玩家第一反应是"我变强了"，直到结局才明白那是什么 |

**夜视的三个约束（弱于手电筒）**：
1. **只辨轮廓，看不清文字** —— 每个夜视节点都显式写"看不清门牌上的字"，因此**不能替代手电筒**（手电版本仍严格更优）。
2. **一处真实机制收益**：`新达汇-2F北走廊中` 的三个海澜之家椅子选项 `showCondition` 由 `canSee` 放宽为 `(canSee || noPainSense)`，高汞玩家在断电黑暗中也能搬椅/钻缝/翻椅。
3. **一处代价减免**：`上实南校-3号楼-4楼-摸黑` 的 `onEnter` 体力 −1 改为仅非高汞时扣（看得清路，不用摸黑磕膝盖）。
