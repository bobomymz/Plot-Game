## 待处理节点

### ① 全家便利店（环林东路）　`story/东明街道/全家和公交站.js:4`

- 现状：`outdoor: true`；`image` 分支为
  ```js
  if (vars.weather === "雨") return "images/小区周边/全家和公交站/全家便利店门口-night.webp";
  return "images/小区周边/全家和公交站/全家便利店门口.webp";
  ```
  即「雨天」返回的是**夜间图**，不是雨天图；`onEnter` 也没有开 `showRain`。
- 后果：下雨时玩家看到的是「夜晚、无雨」的店门口，与天气不符。
- 资源现状：`images/小区周边/全家和公交站/` 下**没有**任何雨天图（只有 `全家便利店门口.webp` / `-night.webp`）。
- 建议修法（三选一）：
  1. **最省**：`onEnter` 加 `{ set: { showRain: true } }`（引擎会用雨滴特效盖在普通图上）；
  2. 补美术 `全家便利店门口-雨天.webp`（+ `-night` 变体）并改 image 分支命名；
  3. 暂无美术时先退回 `images/placeholder.png`。

### ② 金谊广场地面入口　`story/东明街道/金谊广场.js:463`（**真 bug：渲染必坏图**）

- 现状：`image` 函数里 `var f = timeImage({...}); return f;` —— **漏了 `(vars)`**，把 `timeImage` 返回的**工厂函数本身**当成图片路径返回了。
- 后果：`renderScene` 执行 `sceneImage.src = scene.image(...)`，拿到的是函数对象 → 图片路径串成函数源码 → **该节点根本不显示任何图**（晴/阴/雨三种天气均坏图，12 个采样组合全部复现）。
- 额外损失：雨天图资源其实**已经画好并存在**——`images/金谊广场/正门-雨.webp` 与 `正门-雨-night.webp`，但因为没调用工厂，**永远取不到**。
- 建议修法：`金谊广场.js:471` / `:477` 的 `return f;` → `return f(vars);`。
