# 东明街道 · 玩家视角体验报告

> 方式：从 `story/东明街道/樱桃苑（初始小区）.js` 的 `初始卧室` 起步，一次只读一个节点、选一个选项，
> 只在"确认道具来源/确认某分支是不是必死"时才回头查代码。全部结论带文件行号。
> 未覆盖：新达汇（已有独立报告）、金谊广场、警察局、图书馆、长者食堂、五金店、安居苑、上实南校。

---

## 一、结论先行

1. **难度曲线的峰值放错了地方。** Day1 08:00–09:00 这一段集中了全图密度最高的"不可推理死亡"，
   而玩家此刻信息量最少。前 20 分钟真实体验是"找死法图鉴"，不是生存。
2. **真正的压力源是背包格子，不是体力。** 我全程体力维持在 8–10，几乎没被逼到墙角；
   但 3→4 格背包让我连续放弃了防毒面具、电瓶车钥匙、日记本、退烧药，且代价是**延迟暴露**的。
3. **叙事最强的是"林奇暗线"**（寻人启事 / 石蜡油手写标签 / 赵广成口述 / 库房黑皮针筒丧尸，四处互不点破）。
   这是东明街道目前最好的设计，建议按这个标准复制。
4. **NPC 里赵广成最好，周师傅最实用，路霸/郎中最有博弈味**；缺点是四个活人都在"要吃的"，索取物同质。
5. 我查出 **4 处 P0 级必死假选择**、**6 处 P1 级机制不一致/文案错误**，清单在第三节。

## 四、难度曲线

**前 30 分钟最陡，且陡在错误的地方。**
开局 40 分钟游戏内时间里，我遇到 6 个不可推理的死亡点（出门、门缝、按钮、楼梯间、紧急出口、通风管道 50/50）。
这一段玩家还没有任何世界知识，却被要求做出"正确"的选择 —— 惩罚的其实是**探索欲**，这跟末日求生的主题相悖。

**QTE 密度偏高，且与阅读量不匹配。**
几乎每个户外/危险场景都挂着 8–20 秒隐藏 QTE，并随 `chasedByZombies` 递减（地铁站 8→6→4→3 秒）。
中文长文本 + 4~6 个选项，3–6 秒根本读不完。地铁站站台层 3 秒是硬伤级别。

**记忆闪色跳跃陡**：开局 2 色 ×5 / 12 秒 → 药房 3 色 ×7 / 25 秒。三色计数对大多数人是超纲的。

**体力系统被"免费回满点"稀释了。**
全家吃面包/饭团 = `set strength:10`（只花 5 分钟）、床底泡面 +3、食品店 +1/+4、赵广成 +1、理发店过夜 +3。
结果是我全程体力 8–10，**一次都没感受到资源紧张**。
真正的稀缺来自背包格子 —— 这才是这游戏目前最好的压力设计，建议把一部分"回满点"改成"回 2~3 点"，让体力真的成为一条曲线。

**背包压力是真亮点，但代价是延迟暴露的。**
我放弃了防毒面具、电瓶车钥匙、日记本、退烧药。其中"放弃日记本"的后果在几十分钟后才炸：
全家便利店"躲到货架后"的 `condition` 是 `hasDiary`（`全家和公交站.js:153-157`），没有日记本就只能进"结局-脚步声太大啦"。
这种"三十分钟前的取舍回来咬你"的设计很有味道，但前提是玩家能回头想明白 —— 现在回溯/读档的可见性存疑（见"待确认"）。

## 五、剧情新颖性

**做得好的：**

- **林奇暗线（最佳）**：小区墙上撕碎的寻人启事（樱桃苑:986）→ 石蜡油标签手写"——学徒林奇"（益丰:297）→ 库房黑皮针筒丧尸（益丰:339-345）→ 赵广成"你别跟我说你见到谁了，我不想听"（益丰:767）。
  四处信息**互不点破**，全靠玩家自己拼出"我刚才打死的那只就是他"。这种克制的叙事在文字冒险里很少见。
- **日记本自动多出一页当教学**（全家:264-301）：用一篇幸存者日记讲清"迅捷丧尸听觉能辨声源、扔东西没用、要打腿"。
  比任何系统提示都高明，是把机制 diegetic 化的正确姿势。
- **本地化程度**：1003 路公交、珠颈斑鸠、清美生鲜、晨光文具、小笼包与筷子的争论、周师傅的理发店。
  "上海社区末日"的质感是这作最独特的资产，别的地方抄不走。
- **活人比丧尸麻烦**：路霸、假药郎中、方姐三层，给了末日里"人祸"的层次。

**风险：**

- **陷阱型死亡结局太多**：开幕雷击、自由落体、一楼派对、门锁上了、浓郁的香味、厕所惊魂、你太慢啦……
  开局半小时像在集死法图鉴，紧张感被消解成搞笑合集。
  建议把其中一部分改成"付出代价但不死"（受伤 / 掉体力 / 丢物品 / 引来尸潮），把死亡留给真正有铺垫的节点。

## 七、我"作弊"了哪些，对玩家意味着什么

按波波的要求逐条对照：

1. **读了 `core.js` 初始变量和 `utils.js` 的判定函数**（比如 `zombieOutsideHome = dd1 && hh%2==0`）。
   → 真玩家看不到这条规则，只能靠死。当前大量死亡属于"**不可推理**"，玩家学到的不是"读懂世界"，
   而是"别乱点第一个选项"。修法：把隐藏规则变成可见的 diegetic 线索（门缝下有影子在晃 / 门外的拖步声 / 猫眼里那团暗色在动），
   让玩家死得明白。
2. **grep 了 `hasBiscuit` 的来源**，才知道饼干在食品店、且只有 Day1–2 可拿（`dd <= 2`，安盛街:1325）。
   → 玩家既不知道饼干能引怪，也不知道它有时间窗。错过窗口，全家员工通道就只剩"有铁管硬打"或送死。
   **获取难度本身合理**（8 秒 QTE 下抢了就跑，很刺激），但"错过即锁死正解"太硬，建议给一条退化解法。
3. **读了没选的分支来确认死法**（紧急出口三连死、按钮必死等）。
   → 真玩家要为每条假选择付出"死亡 + 重来"的成本。叠加"待确认"里的重开=清档，实际惩罚可能过重。
4. **跳过了新达汇**（用 tools 里既有报告）。
   → 我对"大型商场"这种高密度场景的节奏判断是二手的，本报告不含新达汇的难度评价。
5. **提前知道背包容量公式与帆布袋位置**（部分是玩出来的，部分是记忆）。
   → 首次玩家大概率在民防设施就把 3 格塞满，然后一路丢丢捡捡；我因为知道帆布袋在文具店铁柜，
   少走了至少一次"满包折返"。真实体验会比本报告更局促。

## 八、建议的处理顺序（待波波拍板，我不擅自动数值）

1. 先修 4 处 P0 必死假选择 —— 尤其是 ①开局秒死 ②紧急出口三连死。
2. 修 ⑤"有手电反而堵死"和 ⑦"文案给了饼干、背包没有"。
3. 确认死亡后回溯按钮的可见性，定死"死亡惩罚"到底是撤销还是重开。
4. 把一部分陷阱死亡改成"掉代价但活下来"。
5. 数值类（体力回满点、QTE 秒数、闪色次数、方姐时间窗文案）—— **这些我不动，等你拍板**。

## 九、作者回复与整改结果（2026-09-26）

**波波的三条定性**（推翻了本报告的部分判断，以此为准）：

| 本报告的判断 | 作者定性 |
|---|---|
| 初始小区难度最高且无提示 = 缺陷 | **是设计意图**：该段就是让玩家和创作者博弈、收集死法；可随时撤回，影响不大 → **4 处 P0 不改** |
| 记忆闪色 3 色 ×7 有压力 | **不算难**；真正有压力的是仁济南院正门 ×9 |
| 体力压力被免费回满点稀释 | **不成立**：节点量够探索好几天，不节制地消耗食品，第二天就会陷入疯狂找食物的困境 |
