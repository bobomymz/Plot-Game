# 场景抖动（`shake`）适用位置推荐报告

> 生成日期：2026-09-20 · 工具：`tools/shake_ambush_scan.py`

## 一、机制说明（先确认用法）

引擎侧（`engine.js`）：

```js
// 241-254：一次性动画，自动清理
function triggerShake() { ... container.classList.add("shake") ... }

// 1195-1198：渲染场景时触发
if (enterEffect && enterEffect.shake && !skipOnEnter) {
  triggerShake();
}
```

CSS 侧（`style.css:401-412`）：`translateX(±7px) + rotate(±0.6deg)`，总时长 **0.45s**，`ease-out`。

**用法要点**：

| 要点 | 说明 |
| --- | --- |
| 写法 | `onEnter: { shake: true }`，或与其它键并存：`onEnter: { set: {...}, shake: true }` |
| 兼容性 | `applyEffect()` 只识别 `set` / `add` / `mul`，**`shake` 会被忽略但不会报错**，所以并存安全 ✅ |
| 已自动去重 | 连续两次触发同一场景抖动，`triggerShake()` 内部会先 `remove` + 强制回流再 `add`，重放正常 ✅ |
| 回溯/读档 | `skipOnEnter` 为真时**不触发**，不会在读档时莫名震一下 ✅ |
| 建议 | 只在「进入瞬间是玩家没预料到的冲突」时用。**0.45s 很短**，加在平淡场景上等于白加；加在「已看见丧尸站在那儿」的场景上则没有惊喜感 |

当前全库已使用 5 处：`樱桃苑（初始小区）.js` 的 `家门外的丧尸`/`结局-摇睡丧尸`/`结局-背后的偷袭`/`地下车库的丧尸`/`结局-嘎吱嘎吱`/`民防设施-物资区`。**其余 24 个剧情文件全部为 0**，确实存在大量空白。

### ✅ 关于 #1（李娟-战斗）的写法——已核实可行

`utils.js:411-419` 确认：

```js
function initMemoryGame(colors, len, effect = {}) {
  return function(vars) {
    ...
    return effect; // 其它额外效果
  };
}
```

第 3 个参数**原样透传**给 `applyEffect`，所以只需把 `shake: true` 塞进第 3 个参数的对象里即可：

```js
onEnter: initMemoryGame(["红","蓝","绿","黄"], 4, {
  set: { currentPos: "弘渊楼2F阅览室" },
  shake: true
}),
```

**这是一个通用的发现**：全库 31 处 `initMemoryGame(...)` 都可以用同样方式在闪色 QTE 开场加抖动，无需额外包装函数。

## 五、不建议加的场景类型（避免滥用）

- **普通"看见远处有丧尸"的铺垫场景**（如 `建平-行政楼-1F`、`地铁站-安检区` 首次观察）：玩家预期内，无惊喜。
- **重复进入的高频枢纽**（`三林路`、各十字路口、`新达汇` 各层走廊）：抖动每次进都震，会从"惊吓"退化成"噪音"。
- **纯结局文本节点**（除突袭致死外）：玩家已知必死，抖动无节奏意义；尤其是"犹豫太久被抓"类结局，抖不抖都一样。
- **走廊/场景描述里有"身后"但只是方位词**的场景（如 `新达汇-2F后勤走廊` 的"隔墙传来管道滴答声"）：这是氛围，不是事件。

## 六、实施建议

1. **优先级**：先做 A 级的 #3 / #5 / #6 / #7 / #8 / #9 / #10 / #12 / #13（都是纯文本 `onEnter` 空缺或可直加，零风险）。
2. **需要改函数的**：#1（李娟）、#2（老吴）、#4（益丰偷袭）、#11（楼梯间抉择）——这 4 个 `onEnter` 是函数式，需在函数内调用 `triggerShake()` 并 `return` 原有效果对象，注意不要漏掉原有 `set`。
3. **验证**：改完跑 `node tools/condition_audit.js`（期望两个 0），并用 `node --check` 逐个校验语法。
4. **密度控制**：全库建议控制在 **25-35 处**。目前 5 处 + 本报告 A/B 级共 26 处 = 31 处，正好在合理区间。若全加满会廉价化。
