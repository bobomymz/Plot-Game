用法

  1. 拖入场景图（选「手电筒版」亮图）
  2. 点击图面添加热点，拖动微调，右键删除
  3. 选中热点后在上方改 id / 半径 / 诱饵
  4. 勾「光锥预览」自测：黑图里用手电圈扫，能否在 5–15 秒内找到目标
  5. 复制导出代码，贴进场景数据的 darkSearch 字段
坐标 = 图片原始宽高百分比（0–1），游戏内 16:9 裁切由引擎换算。红框 ⚠ = 该点会被 16:9 裁掉。热点按 图片名+大小 自动存档。
