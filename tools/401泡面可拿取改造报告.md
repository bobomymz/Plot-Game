## 三、⚠ 关键坑：引擎走 `elseScene` 时不执行选项 `effect`

`engine.js:875 createChoiceButton` 的 click handler：

```js
if (nowCondMet) { if (choice.effect) applyEffect(choice.effect); currentScene = parseRedirectTarget(choice.nextScene); }
else            { currentScene = parseRedirectTarget(choice.elseScene) || parseRedirectTarget(choice.nextScene); }  // ← 不跑 effect
```

所以「背包满 → `elseScene` 整理整理」时，选项 `effect` **不会执行**。
`positionAfterOperation` 若写在 **option effect** 里，背包满的玩家整理完就回到一个**旧值**（或空串 → `nextScene: "{positionAfterOperation}"` 解析到不存在的场景）。

**正确做法**：由**入口场景 `onEnter` 预设**（项目既有模式：`三林安居苑-小广场` 的 `onEnter` 就写死了 `positionAfterOperation = "三林安居苑-滑板车"`）。
本改在 401 的 `onEnter` 预设 `"三林安居苑-7号楼-401-拿泡面"`——整理完腾出空位即**直接完成本次拾取**。

# 七、v2 追加：割锯类工具门槛（2026-09-29 同日）

## 7.1 需求

> "这半箱泡面可能拿得有点容易……必须有美工刀才能拿到，没有美工刀徒手撕不开箱子还扣体力。为了防止玩家用美工刀打开后把美工刀丢了导致后续拿不了，需要用 `_visit['吃泡面的节点']` 辅助判定。"
> —— 后澄清："不只是美工刀，**割锯类物品都行**，就像新达汇找到的那个一样。"

即：口径与 `新达汇-1F后勤仓库`（划开两箱矿泉水）完全一致 —— 用 `cuttingToolName(vars)`（**美工刀 > 匕首 > 斧头 > 螺丝刀**，不含铁管/拐杖/拖把杆）。

## 7.2 改动前 → 后

| | v1（可拿取） | v2（加工具门槛） |
|---|---|---|
| 首入 401（箱未开） | 「拿走一包泡面」直接可点 | 有割锯工具 → 「用<工具>划开纸箱」；无 → 「试着徒手撕开纸箱」 |
| 徒手 | — | 进「撕不开」节点，**扣 1 体力**，箱子保持原样 |
| 开箱 | — | 进「划开纸箱」节点（一次性，`_visit` 记录），此后不再校验工具 |
| 开箱后丢工具 | — | **仍可继续拿**（核心需求） |

## 7.3 改动清单（5 处，全在 `story/东明街道/安居苑.js`）

1. `三林安居苑-7号楼-401` 屋内 `choices`：加 `opened = _visit['三林安居苑-7号楼-401-划开纸箱'] > 0` 判定 —— 未开则按 `cuttingToolName` 出「划开 / 徒手」；已开则出原拿取选项。
2. 同上 `text`：箱未开 → 「那半箱泡面封在纸箱里，胶带缠了好几层」；已开 → 「…箱口的胶带已经被你划开了」。
3. **新增** `三林安居苑-7号楼-401-划开纸箱`：`onEnter: updateTime(2, { set: { positionAfterOperation: "…-拿泡面" } })`，文案含 `<span class='sfx'>啪</span>` 与「纸箱已划开」提示，出口可拿一包 / 先不拿。
4. **新增** `三林安居苑-7号楼-401-撕不开`：`onEnter: updateTime(1, { add: { strength: -1 } })`，文案「徒手撕不开——需要美工刀这类能割开胶带的东西」+ 橙色体力提示。
5. 顺带修既有小瑕疵：401 屋内 `text` 加 `_lastScene` 分流 —— 从「破门」进来才播字条开篇，从屋内子节点折返改「你回到401屋里」，不再重播开篇。

> **无新增变量**。`_visit` 由引擎维护，`_flat401NoodleLeft` / `_flat401` 语义不变，故 **`core.js` 与 `engine.js` 本次零改动**（v1 的旧档迁移块继续有效）。

## 7.4 关键机制：为什么用 `_visit` 记录「箱子已开」

`_visit` 由引擎在**进入场景时自增**（`_visit[id] > 0` 即"来过"）。把"划开纸箱"做成**独立节点**，玩家一旦进入即留下痕迹：

- **箱子状态从"玩家当前的工具"解耦** —— 开箱是**世界状态的一次性改变**，不该因为玩家之后丢了美工刀而回滚。
- `_visit['三林安居苑-7号楼-401-划开纸箱'] > 0` ⇒ 箱子已开 ⇒ 直接给拿取选项，不再看 `cuttingToolName`。
- 这正是新达汇 `_visit['新达汇-1F后勤仓库-开箱']` 的同一模式，**本项目里"一次性开启动作"的通用写法**。

⚠ 键名字符串必须**逐字等于真实场景 ID**（`三林安居苑-7号楼-401-划开纸箱`）；悬空键不报错、条件恒假，会导致选项永不出现。

## 7.5 平衡影响（待波波拍板）

| 项 | 取值 | 说明 |
|---|---|---|
| 徒手失败扣体力 | **−1** | 与"白费力气"相称；体力见底会走全局触发器 `strength <= 0.01 → 结局-体力耗尽`（与全项目扣体力惯例一致） |

> 以上三处是**数值**，若你想更重/更轻，改这三个数即可（各一处）。
