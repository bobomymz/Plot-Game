## 四、⚠ 本次踩的坑（三条，都写进脚本注释了）

### 1. 最危险：拟声词污染了**场景 ID**（静默 bug）

`"结局-嘎吱嘎吱": {` 里的「吱」命中 sfx 规则，被插成
`"结局-嘎<span class='sfx'>吱嘎吱</span>": {`。

- **语法完全合法、lint 也不报** → 只有 `scene_fn_selftest` 的死链检查抓到
  （`地下车库的丧尸 · nextScene 指向不存在的场景：结局-嘎吱嘎吱`）。
- 后果：玩家点进这个分支**直接死链**。
- 防护已加：① 场景 ID 定义行（`^\s*"…":\s*\{`）整行跳过；② **ID 形态禁区**
  —— 引号内、≤28 字符、不含空格与中文标点的串一律不处理。

### 2. 引号不是边界 → `<span>` 插到字符串外面

`return "你从背后扑上去…"` 中「扑上去」向前扩过了起始引号，插成了
`<span class='crit'>      return "你从背后扑上去</span>`，**JS 语法直接崩**（安盛街.js）。
防护：`"` `'` `` ` `` 全部加入分句边界集。

### 3. 续行符 `\` 会被吃进选区

行尾 `\`+换行是续行，选区一旦吃进去就变成 `\</span>` + 换行 → 语法崩。
防护：`\` 加入边界集；同时源码字面 `\n` 先换成等长探针字符再判边界
（否则会切出 `n远处传来…` 这种残缺选区）。

> 顺带一条：本项目有**整点 auto-commit**。我在回滚时用 `git checkout -- story/东明街道`
> 以为回到了 P1 基线，实际回滚到的是「已被自动提交进去的、含污染 ID 的版本」，
> 于是污染反复出现。**回滚必须显式指定基线 commit**：`git checkout d31974a -- story/东明街道`。
