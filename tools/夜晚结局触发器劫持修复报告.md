# 夜晚死亡结局被全局触发器弹回过夜菜单 —— 修复报告

> 日期：2026-10-01　报告人：波波（Day 2 在自己家过夜应触发死亡结局，实际弹回「天黑必须过夜」）
> 自测：`node tools/night_ending_bounce_selftest.js`　**改动文件：仅 `engine.js`（renderScene 一处守卫）**

## 一、结论

**不是过夜选项的 condition 写错，是引擎级冲突**——波波的判断正确。`renderScene` 进入任何场景后都会跑全局触发器检查且没有结局豁免；夜晚 `hh >= 19` 时，「天黑必须过夜」触发器（priority 5）在死亡结局落地的瞬间再次命中，把玩家弹回过夜菜单。**结局画面永远不可达。**

## 二、链路（修复前）

1. Day 2 夜里（`dd=2, hh≥19`）点「睡在自己家」；
2. `condition: "dd == 1"` 为假 → 走 `elseScene: "结局-过夜-自己家不再安全"`（这部分**符合设计**：Day 1 限定）；
3. `renderScene("结局-过夜-自己家不再安全")` → onEnter（**无**，hh 停在 19+）→ `checkGlobalTriggers()`；
4. `hh >= 19` 仍为真 → `resolved("天黑必须过夜") !== currentScene(结局)` → **弹回过夜菜单**。

**为什么 Day 1 正常**：「过夜-自己家」的 onEnter 先把 `hh` 拨回 7，触发器不再命中。所有过夜安全屋都有这一步，所有死亡结局节点都没有——所以只有「夜晚直达的死亡结局」中招。

**为什么白天死亡看起来正常**：触发器目标本身是结局的（`结局-体力耗尽` / `结局-汞中毒尸变` / `结局-尸潮撕碎了你`）因 `resolved === currentScene` 天然豁免。**受影响的是"非触发器直达"的结局**：过夜菜单的全部死亡陷阱（自己家/楼道/全家/联华/图书馆/深夜食堂/建平 19·20）、以及夜晚 QTE 超时进的各种死法。

## 三、修复（engine.js renderScene，约 ：1478）

```js
const isEndingScene = sceneId.startsWith("结局") ||
  (typeof scene.text === "string" && scene.text.includes("—— 结局："));
if (!isEndingScene) {
  const triggeredScene = checkGlobalTriggers();
  if (triggeredScene) { /* 原跳转逻辑不变 */ }
}
```

- 语义：**结局场景是终态，不再响应全局触发器**。触发器目标本身是结局的原先就天然豁免，此守卫补齐其余结局。
- 第二条判定覆盖非「结局」前缀的结局——全库仅 4 个且均为静态文案：`五金店-货架躲藏`、`上实南校-图书馆-全灭`、`三林安居苑-厨房危险`、`建平-结局-空枪`（函数式文案结局的 ID 均带前缀，已核对）。
- 不 bump `SAVE_VERSION`（不改任何字段含义，旧档无感）。
