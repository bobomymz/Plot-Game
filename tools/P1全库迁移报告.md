## 三处会改变观感的地方（需要你确认）

### ① 系统提示青色变柔和 —— 116 处
`#00fbffff`（刺眼亮青）→ `--sys #4ec9d4`。**这就是你批准的第 ⑥ 项。**
橙色那 97 处（`warn` / `sys warn`）沿用既有 `#ffaa00`，观感不变。

### ② 结局行 122 处 —— 全库最大的观感增量
原来结局行和普通正文**长得一模一样**，现在统一成干血红 `--blood #9e2a22` + 字距 0.2em + 1.05em。
这是 P1 里唯一"凭空多出来的"视觉信号，也是最值钱的一处——玩家现在一眼能看到自己是不是死了。

### ③ 四小类顺手语义化（12 处）
- 妈妈的微信 ×2：`#aaa` 灰 → `term` 冷青（带辉光）——手机上读的，该有屏幕感
- 日记本正文：`#bfb7a3` → `hand` 手写楷体暖白；页码 → `clock`
- **【好感度 ±N】×3：粉色 → 青色**（唯一把粉色改掉的决定，理由是"UI 反馈 = 系统提示"）
- 彩蛋小字（"你是4217人中第一个达成此结局的玩家。"）×4 → `numb`
