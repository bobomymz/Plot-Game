## 三、两处规则缺陷（真 bug，已全库修）

### ① 长词表缺复合拟声 → 半截放大（第一批遗留 + 第二批同源，共 28 处）

「嘎吱 / 吱嘎 / 哐当 / 咣当 / 叮铃」不在长词表，被单字规则命中**半个字**：

```
门锁发出令人牙酸的嘎<span class='sfx'>吱</span>声     ← 「吱」被放大、「嘎」没有
刮得路牌<span class='sfx'>吱</span>嘎作响             ← 「吱嘎」被拆
```

**半个词放大比不标更难看**。分布：第一批遗留 18 处（东明社区图书馆 / 东明街道路径 / 全家和公交站 ×3 / 反派NPC / 地铁站 / 安居苑 / 安盛街 ×2 / 新达汇 ×3 / 新达汇地下车库 / 樱桃苑 ×3）+ 第二批 10 处（仁济 ×3 / 建平 2239 / 张江 ×2 / 夜晚 …）。

**修法**：长词表补 `吱嘎|嘎吱|哐当|咣当|叮铃铃|叮铃`。

### ② 合并检查排在配额之后 → 「砰砰砰」被拆

`建平中学.js:2239`「砰！砰砰砰！」：`砰砰` 先占满段内 sfx 配额，紧跟的 `砰` 在配额判断处被拦、**永远走不到合并分支**：

```
修复前：<span class='sfx'>砰</span>！<span class='sfx'>砰砰</span>砰！
修复后：<span class='sfx'>砰</span>！<span class='sfx'>砰砰砰</span>！
```

**修法**：**相邻同类合并前移到配额判断之前**（合并只是并入已有 span、不新增配额）。

### 还原工具

新增 `tools/markup_fix_split_sfx.js`：把已落地的「半截 span」还原为纯文本（只还原能与邻字拼回完整拟声词的），随后重跑迁移器即整体包好。幂等，`--apply` 写入。

## 四、新增守卫

### 守卫一：场景级 style（`engine.js:1531`）

引擎把 `scene.style` 直接刷在 `#scene-text` 容器上。全库 **28 处死亡结局场景**带 `style:"color:#ff4444;font-weight:bold"` —— **整段正文已是红+粗**。

- `crit`（红粗）在其内 **零视觉增量**；`rot`（脏黄绿）会破坏整段统一的死亡红。
- 脚本按行判定场景块是否带 style，其内 **crit/rot 跳过、sfx 保留**（sfx 是字号放大，不依赖父级 color）。
- 本批因此跳过 4 处：仁济 `756`（结局-急诊失守）、仁济 `1625`、夜晚 `536`（结局-全家夜袭）、夜晚 `694`。

### 守卫二：机械声非丧尸声

`rot` 的「低吼」会误命中**发电机**。张江动力站「发电机低吼着，水泵喘着」被两次命中 → 加守卫词表 `发电机|水泵|电机|马达|引擎|机器|风机|配电`。
