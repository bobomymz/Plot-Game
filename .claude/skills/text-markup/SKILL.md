# 剧情文本视觉标记（语义 class）

正文支持行内 HTML，但**只写语义 class**（`<span class='crit'>`，单引号，复合类空格连接如 `sfx crit`），禁 inline style。

该体系已经五金店/长者食堂/复旦江湾三个样板 + P1 全库迁移验证（2026-09-28 完成：inline style 270→0、结局行 129 处 `end`、全库 lint E=0）。 ——9/28

**核心信念：最大的风险不是技术，是用力过猛。** 1470 场景 8.6 万字，逐词着色会变圣诞树。一切上色决策过配额制 + 密度开关（见「写作规则」）。

## 硬约束（引擎事实，违反 = 静默破坏画面）

| 约束 | 后果 |
|---|---|
| 正文只能用**行内**标签（span/b/i/em/small/mark/code/q/sub/sup/br） | `#scene-text` 是 `<p>`，块级标签（div/p/ul/table…）被浏览器自动闭合 → 后半段文字掉出面板。lint 直接报 E |
| 正文走 `innerHTML` **不过滤** | `sanitizeInlineHtml` 只管**选项**；正文里裸 `<` `&` 会被当标签吞字 |
| `{变量}` 可写在标签内部，**禁写在标签属性里** | lint 报 E |
| 打字机遇到 `<` 整段一次性插入 | 持续型 CSS 动画每帧重启（抽搐），不可用 |
| 新增 class 必须**三处同步** | `style.css` 定义 + `engine.js` 的 `CHOICE_HTML_CLASSES`（L820）+ `tools/text_markup_lint.js` 的 `ALLOWED_CLASSES`。漏同步 lint 报 E |

## class 速查（23 个）

> 本表的语法权威版本在 `docs/引擎语法手册.md`「正文与选项的 HTML 标记」节（含白名单与两条渲染通路），两处同步。

| class | 用途 | 要点 |
|---|---|---|
| `sys` / `sys warn` / `sys crit` | 【系统提示】青/橙/红 + 斜体 | 体力±、受伤、危急提示 |
| `warn` | 警告（非 UI） | 橙 |
| `crit` | 突袭/咬伤/致命瞬间 | 红 + 粗，包动作句 |
| `sfx` | 拟声词 | 黑体 **1.35em 放大**；碎裂/枪响/撞击加 `sfx crit` |
| `shout` | 喊叫/命令 | 1.15em，包整句含中文引号 |
| `rot` | 丧尸嘶吼/尸性描写 | 脏黄绿，只包丧尸的声音/动作，不染人的惨叫 |
| `smell` | 气味 | 褐黄斜体，**统一一色不分档**（拍板④） |
| `think` | 心理活动（"玩家察觉到但没说出口"） | 暖灰斜体，主线串意象用 |
| `mem` | 回忆画面（照片/展板/旧场景浮现） | 淡紫 |
| `hand` | 有人**亲手写**的字（字条/遗书/便签/日记正文） | 楷体暖白 |
| `print` | 印刷体（告示/标签/表格/公文引文） | 宋体加字距 |
| `term` | 电子屏（手机/微信/面板/监控/签到机） | 等宽冷青 + 辉光 |
| `sign` | 招牌/门牌/横幅 | 亮黄黑体 |
| `num` | 数字/编号/密码 | 等宽磷光绿 + 粗 |
| `clock` | 时间/日期（客观时间戳） | 等宽小字灰 |
| `leaf` `water` `fire` `dust` `gore` | 环境色（植被/水雨/火光/尘雾/血迹） | **只包整句或分句** |
| `chem` | 化工/汞异常感知 | 银绿重影（拍板⑤允许的视觉暗示） |
| `numb` | 麻木/体征（汞中毒无痛觉） | 冷灰 |
| `end` | 失败结局行 `—— 结局：X ——` | 暗血红 + 粗 + 字距 0.2em |

配色实样：浏览器打开 `tools/text_style_preview.html`（含三样板实拍 + 密度对照表）。样式定义在 `style.css`（约 L243 起）。

## 写作规则（样板验证过；违反 = 过花或语义错）

1. **一字不增删，只包不改写**。为上色造拟声词 → 回退（复旦样板有自我否决先例）。
2. **台词一律不上色，越关键越留白**。喊话是唯一例外，走 `shout`。
3. **`sfx` 只包拟声词本身**——1.35em 放大，包长句很突兀（P1 先例：全家开门声整句包 sfx → 改回 `<b>` 保真）。连排拟声（「砰！砰砰砰！嘎吱！」）整串包**一个** span，尾部长破折号一起包（样板先例：长者食堂 L84「砰砰砰————！」）。
4. **配额**：单段（一个 `\n` 分隔的自然段）≤2 处强调类（crit/sfx/shout）+ ≤1 处环境类；环境色只包整句/分句（4–25 字），不包单词；同一 class 不在相邻两句连用。
5. **密度开关 = 三问**：这节点要不要死人（危险类 crit/rot/end）？这段从哪读来的（载体类 term/print/hand/sign）？玩家此刻在想什么（内心类 think/mem）？日常点靠 term/print 做信息分区，其余留白。
6. **密度标定**：陷阱屋（五金店）≈30 字 1 处；日常探索 60–100 字 1 处。类型构成比总数更影响观感（三样板危险类占比 45% / 12% / 26%）。
7. **QTE 战斗开场句**（「X扑了过来！」）包 `crit`；QTE 提示行（「集中注意力…」）`warn` 是既有惯例，不动。
8. **可拾取物不高亮**（拍板①）；**不用颜色暗示哪个选项是对的**（防剧透）；不做 NPC 角色色、不做块级排版、不做逐词着色。

## 迁移与排查

- **inline style、裸结局行、`**` 残留都是回潮 bug**（P1 已清零，新写的剧情别再产出）。发现即用 `tools/markup_migrate_p1.js`：无参数 = 普查（按「颜色+斜体+粗体」三元组分组）、`--apply` = 替换、`--end` = 结局行、`--md` = 星号残留。**任何 `--apply` 前必须先跑无参数普查**（硬规矩）。同一组合内语义分裂的点不进映射表，人工逐个定。
- lint 报 E 对照 `text_markup_lint.js` 头注释五类：块级标签 / 非白名单 class / 标签未闭合 / 属性里写 `{变量}` / 裸 `<` `&`。

## 常见错误

| 错误 | 后果 |
|---|---|
| 写 inline style 颜色 | 绕过色板，改配色时漏掉（P1 前 270 处的债） |
| 块级标签 / `<div>` | 撑破段落，文字掉出面板 |
| class 拼错 | 样式静默失效，无报错 |
| span 未闭合 | 后半段整段被着色 |
| `sfx` 包整句 | 放大突兀 |
| 给 NPC 台词上色 | 语义错，台词靠留白出节奏 |
| 逐词着色 | 圣诞树，没人看正文 |
| 选项里写非白名单 class | 被 sanitize 降级：文字保留但样式丢 |
