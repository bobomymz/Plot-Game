### 教训

- **`// ─── 空编辑陷阱`**：本轮我几次用 Edit 做"仅调整空行"的调用，其中 2 次把相邻行**粘成一行**（`}      if (...)`、`: {    image:`）。语法仍合法、所有审计都不会报，但**格式被破坏**。**规则：不要用 Edit 做纯空白调整**；改完必须 `grep -nE "}      [a-z]|: {    "` 扫一遍粘连痕迹。
- **上一轮报告里我捏造了一条不存在的原文**（张江"没有你要的答案"）。**教训：报告里引用原文必须先 grep 核实**，不能凭印象写——这条如果没被作者追问，就会变成一个假的"设计冲突"堵住正确的实现路径。
