## 抖动动画（shake）适用位置排查（2026-09-20）

**产出**：`tools/抖动动画适用位置推荐.md`，扫描工具 `tools/shake_ambush_scan.py`。

**机制确认（3 个关键点）**：
1. `applyEffect()` 只认 `set`/`add`/`mul`，`shake` 会被静默忽略 —— 所以 `onEnter: { set: {...}, shake: true }` 并存安全，不会报错。
2. `triggerShake()` 内部先 remove + 强制回流再 add，同场景连续触发可正常重放。
3. `skipOnEnter`（回溯/读档）为真时不触发，读档不会莫名震动。

**重大发现**：`utils.js:411` 的 `initMemoryGame(colors, len, effect={})` 把第 3 个 effect 参数原样 return（`return effect`）。所以全库 31 处闪色 QTE 都能直接写
`onEnter: initMemoryGame([...], n, { set: {...}, shake: true })` 加抖动，无需包装函数。这是给「闪色开场 = 突袭瞬间」加抖动的通用通道。
