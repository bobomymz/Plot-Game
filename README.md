# 尸潮笔记 / Zombie Notes

> 一款纯前端、零依赖的中文选择驱动型丧尸末日生存视觉小说。
> 在丧尸末日中，你是一名刚毕业的高中生，将从家里开始你的逃生之路。
> 每一个决定，都通往截然不同的结局——丧尸的凝视、路人的相助、真相的浮现……你会走到哪一步？

---

## 🎮 玩法简介

- **超大规模分支剧情**：1300+ 个场景节点、100+ 种结局。从东明街道的家中出发，探索小区、学校、商场、医院、地铁站，乃至驶上上海高速路网——你的选择决定剧情走向、角色存亡与物品收集。
- **生存数值系统**：体力、饥饿、疲劳、受伤、感冒层层叠加；游戏内时间（Day/时/分）真实流逝，入夜后必须寻找安全屋过夜。
- **实时反应系统（QTE）**：关键时刻限时抉择，超时即承受致命后果；尸潮追击等级越高，给你的反应时间越短。
- **记忆闪色战斗**：屏幕上颜色飞速闪过，记住它们的颜色分布并正确输入，才能在遭遇战中活下来。
- **背包与武器管理**：背包容量有限，取舍是常态；近战武器分档位、有耐久，断了就得想办法再找一把。
- **天气与世界状态**：晴天/阴天/雨天影响行进速度与体力消耗；你的行为（探索次数、枪声、逗留）会悄悄改变丧尸的分布与追击等级。
- **多区域大地图**：东明街道（樱桃苑、安居苑、新达汇、金谊广场、菜市场、图书馆、警察局……）、建平中学、仁济南院、张江，以及连接一切的上海市区高速路网。
- **多结局与黑色幽默**：从正统存活到离奇搞笑，死亡结局也是游戏体验的一部分——回溯系统让你随时重来。

## 🛠️ 技术栈

- **前端**：原生 HTML5 / CSS3 / JavaScript，零依赖、无构建步骤
- **引擎**：自研数据驱动对话树引擎（`engine.js`，约千行），支持变量系统、条件跳转、响应式规则、全局触发器、QTE、输入框、记忆闪色、屏幕特效与图片查看器
- **剧情数据**：全部场景为纯数据（`story/*.js`，`Object.assign(storyData, {...})`），引擎与内容完全分离
- **图片素材**：WebP 静态场景图（`images/`，按区域分目录）

## 📁 项目结构

```
index.html          → 入口，按顺序加载所有脚本
style.css           → 全部 UI 样式
engine.js           → 核心引擎
story/
  core.js           → storyData 声明、变量、响应式规则、全局触发器、屏幕特效
  utils.js          → 工具函数/工厂（时间推进、记忆闪色、武器耐久、过场动画等）
  夜晚剧情.js       → 天黑强制过夜系统
  东明街道/         → 前期主区域（一文件一地点）
  仁济南院.js       → 仁济医院（西南线）
  建平中学.js       → 建平中学（北线）
  张江.js           → 张江区域
  上海市区路径.js   → 高架/立交/城市级连接
images/             → 场景图（WebP），按区域分目录
```

剧情创作规范与引擎能力清单见 `CLAUDE.md`；世界观设定见 `核心设定3.0.md`、`人物档案.md`、`设计细节.md`。
