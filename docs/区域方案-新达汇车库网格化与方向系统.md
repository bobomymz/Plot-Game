## 1. 网格结构

### 1.1 坐标系

北=上，行优先字母（A B C 为北排）：

```
        北
   A  B  C     ← 北排（深处/旧区方向）
   D  E  F     ← 中排
   G  H  I     ← 南排（入口方向）
西              东
```

- 每格坐标 `(x, y)`：A=(0,2) B=(1,2) C=(2,2) / D=(0,1) E=(1,1) F=(2,1) / G=(0,0) H=(1,0) I=(2,0)。
- **扩容规则**：向北加一行 J K L（y=3）即可变 3×4；字母行优先天然支持。
- 邻接只走正交（不加斜对角），角落 2 邻、边 3 邻、中心 4 邻。

### 1.2 数据结构（邻接表 = 唯一权威）

```js
// 文件顶部常量，lint_story / graph_audit 可直接读取（替代 __sceneRefs 补边）
var XDGRID = {
  "新达汇-B1-A": { x:0, y:2, N:"新达汇-B1-B", S:"新达汇-B1-D", E:null, W:null },
  // ... 9 格
};
```

### 1.3 旧 12 区 → 9 格映射（建议稿，待拍板）

| 格 | 方位 | 承接内容（原区） |
|---|---|---|
| **A** | 西北 | 西侧车道北段（原 G 区面包车），贴旧区 |
| **B** | 北 | 旧区排水沟段（原 D 区）——标高特殊，见 §2.2 |
| **C** | 东北 | ★车道尽头·事故点（原 F 区），小明的深灰荣威 |
| **D** | 西 | 西侧车道南段（原 G 区南半） |
| **E** | 中心 | 中段枢纽（原 I 区，"正"字立柱） |
| **F** | 东 | 第二停车排（原 K+L 合并） |
| **G** | 西南 | **入口平台**（原 A+J 合并：坡道口、收费亭、疏散图、断杆） |
| **H** | 南 | 主通道南段（原 B 区） |
| **I** | 东南 | 拐角杂物堆（原 H 区，检修通道 POI） |

- **不占格的 POI**（挂为格内行动选项，同现在"搜查拐角的车"模式）：
  - 配电室（原 C 区 + 接线谜题 3 节点整体保留）→ 挂 H 或 B 格防火门；
  - 涂鸦（原 D 区附属）→ 挂旧区格；
  - 疏散图 → 挂入口格。
- 入口格（G）保留跨日噪音衰减结算（`_garageLastDay` 比较是幂等的，回头重跑安全）。
- 事故点（C 格）四态文案（车没来/车在没通电/打赢未走/车已开走）原样迁入。

### 1.4 旧区标高（设计分叉，待拍板）

原 D 区"低一层"是平面网格装不下的。两个方案：

- **方案 A（推荐）**：网格只覆盖 B1 主地面；旧区作为 B 格挂的"下行 POI"独立小节点（走下台阶 → 旧区小场景 → 涂鸦/观察排水沟 → 爬上来）。网格不动，标高不破坏。
- **方案 B**：B 格标注高差，进入该格的边全部标"经台阶/斜坡"，文案上处理。网格纯度略降，地图更整。

## 2. 方向系统

### 2.1 状态变量

| 变量 | 含义 | 默认值 | 登记 |
|---|---|---|---|
| `_garageFacing` | 玩家朝向 N/E/S/W | `'S'`（进库面向车库内=朝北时由来向修正，兜底 S） | `fillMissingDefaults`；只加变量，不 bump SAVE_VERSION |

- **进场初始化**：onEnter 读 `_lastScene`，若它也在 `XDGRID` 中 → facing = 从邻格指向本格的方向（走进来自然朝前）；从外部（B1走廊/辅路）进 → facing 固定为"朝库内"。
- **回溯兼容**：`backtrack()` 跳过 onEnter 但恢复整个快照，`_garageFacing` 随快照自动回滚，无需特殊处理。`countSceneChoices` 已支持函数式 choices（engine.js:789），回溯落点判定无损，且网格格点普遍 ≥4 选项，回溯体验只会变好。

### 2.2 文案三层合成（避免 4 朝向 × 9 格 = 36 变体全手写）

每格正文 = **进格句**（按来向方位生成）+ **格内固定细节**（手写 1 段/格）+ **方位罗盘句**（自动拼装）：

```js
// 手写量：9 段固定细节 + 36 条方位短语（每格每方向一句 15~30 字）
var XDGRID_LABELS = {
  "新达汇-B1-E": { N:"北面，横道继续往深处延伸", S:"南面透着一点应急灯的光——入口的方向",
                   E:"东边是第二停车排，车影挤着车影", W:"西边，车道沿旧区的边延伸过去" },
  // ...
};
```

- 罗盘句只显示**当前朝向相关的方位**（前方一句为主，左右若探明可缀一句），不是四面全报，避免信息过载。
- **黑暗降级（沉浸增强点）**：`xdGarSight` 为 `dark` 时不给罗盘句，只留触感句（"左手边是墙"级别的模糊方位）；`dim` 时只显示已到访过的方向（`_visit[邻格]>0`）。方向感本身成为照明状态的一部分。

### 2.3 选项四个固定槽位

每格 choices 为函数，按固定顺序生成：

1. **前进**（`前：北面的车道`）→ 无邻格/死路时按 §2.4 处理；
2. **左转**（原地转向，`左转：面向西`）；
3. **右转**（同上）；
4. **后退/掉头**（`= 转身 180°`，驾驶模式即倒车掉头）；
5. 之后追加该格 POI 选项（搜车、配电室、涂鸦、下车……）。

- 转向后**不重渲染正文也要重渲染**——转身是 choices 内 effect 改 `_garageFacing` + `nextScene: 当前格`？⚠ 注意：自跳转会让 onEnter 重跑（onEnter 有 guard 的量必须幂等）与 `positionAfterOperation` 类回头检测冲突（`transit` 的回头追兵逻辑只在跨区移动，自跳转 `_prevPos2` 不变，不触发——需自测确认）。**替代方案（推荐）**：转向选项用引擎"原地刷新"路径——若引擎无此机制，则转向 = `nextScene: 自身`，靠 onEnter 幂等 + 不走 `transit` 兜住，列入自测用例。

### 2.4 死路方向（待拍板）

- 方案 A：无邻格方向的"前进"槽位**隐藏**（showCondition 函数返回 false）。
- 方案 B：显示但换成环境句（"前面是墙，喷着褪色的车位编号"），点按不移动不耗时。

## 3. 引擎能力核对结果（2026-10-02 实测 engine.js）

| 能力 | 结论 | 证据 |
|---|---|---|
| `scene.choices` 为函数 | ✅ 渲染主路径 + 回溯计数都支持 | engine.js:951-954、789-791 |
| `choice.text` 为函数 | ✅ | engine.js:861 |
| `condition` 为函数 | ✅ | engine.js:542-544 |
| `showCondition` 为函数 | ✅（走同一个 checkCondition） | engine.js:796→542 |
| **选项顺序** | ⚠️ **renderChoices 默认打乱顺序**（防肌肉记忆），engine.js:957-961 | 见 §3.1 |

### 3.1 必要的引擎改动：选项定序开关

前后左右是**空间方位**，被 shuffle 打乱后方位感直接崩坏。需给引擎加最小开关：

```js
// renderChoices 内，shuffle 前加一行：
if (!scene.fixedChoices) { /* 原有 shuffle */ }
```

- 网格格点场景设 `fixedChoices: true`；其他区域行为不变，零回归风险。
- **这是本方案唯一的引擎侵入点。**

## 6. 待波波拍板的设计分叉

1. **旧 12 区 → 9 格映射**：按 §1.3 建议稿，还是你自己排？（可只改表格）

6. **移动耗时统一为 1 分钟**：接受这个平衡变化吗？（涉及难度，按惯例记录待批）
