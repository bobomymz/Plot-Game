## 自动推送（AutoPushGame）

Windows 任务计划程序创建了 `\AutoPushGame` 定时任务，每小时自动提交并推送代码到 GitHub。

### 脚本位置

- `C:\Users\wgdin\auto-push.sh` — 由 Git Bash 执行
- 日志：`C:\Users\wgdin\push-log.txt`（追加模式，保留历史）

### 推送逻辑

```
git add -A
git commit -m "auto: 时间戳"
git push origin main（先试直连）
  └─ 直连失败 → 走代理 http://127.0.0.1:7890 重试
```

### 注意事项

- Git 全局配置了 `http.proxy=http://127.0.0.1:7890`（Clash/VPN 代理）
- 脚本会先尝试绕过代理直连，失败再走代理，避免代理未开启时推送失败
- 如需查看上次推送结果：`cat /c/Users/wgdin/push-log.txt`
- 定时任务位置：Windows 任务计划程序 → 任务计划程序库 → `\AutoPushGame`
- 更新计划：每 1 小时，最早 9:00，最长运行 72 小时。此计划可能发生变化，如有需要，请自行查看最新计划。

## Serena MCP（符号级代码智能）

Serena 是基于 LSP 的代码智能 MCP（符号查找、跨文件引用、引用感知重命名、符号级编辑），2026-10-02 在本项目配好可用。

### 工具优先级（重要，Serena 官方强调）

**查代码/改代码时，优先用 Serena 的工具，而不是 Claude Code 自带的 Read / Edit / Grep。**

原因：Serena 的操作建立在语言服务器解析出的符号结构上，比行级文本替换更安全——`rename_symbol` / `safe_delete_symbol` 引用感知、全库原子一致；`replace_content` 命中多处时会报错而不是猜一个。而 Claude Code 在无提示时**默认倾向自带工具**，所以这里必须显式写明：

| 任务 | 用 Serena 的 |
|---|---|
| 浏览/定位代码 | `get_symbols_overview` → `find_symbol`（按需 `include_body`） |
| 查谁在调用/引用 | `find_referencing_symbols` |
| 改整个函数体 | `replace_symbol_body` |
| 改几行 / 跨文件批量替换 | `replace_content` / `replace_in_files`（先 dry_run） |
| 重命名 / 删除符号 | `rename_symbol` / `safe_delete_symbol` |

例外（Serena 覆盖不到的，仍用原有工具）：`story/*.js` 的中文场景 key 是数据字面量，物品/flag 审计用 `tools/chain_audit.mjs` 等；"这段逻辑怎么跑的"这类理解型问题用 CodeGraph（`codegraph_explore`）一次拿调用链，两者互补。

### 环境依赖（三件套，缺一即退化）

MCP 配置在用户级 `~/.claude.json`：`serena start-mcp-server --context=claude-code --project-from-cwd`。

1. **全局 npm 包**：`npm install -g typescript-language-server typescript`
2. **`.serena/project.yml`**：`language_servers: [typescript]`（JavaScript 对应的 id 就是 `typescript`）
3. **根目录 `jsconfig.json`**：`{"exclude": [".workbuddy"]}` —— 无它则 tsserver 按文件建独立"推断项目"，**跨文件引用/重命名全部失效**（同文件正常，症状隐蔽）

### 排障速查

| 症状 | 原因 | 修法 |
|---|---|---|
| `No language servers available in the manager` | npm 包未装，或 project.yml 是空表 | 装包；手改 `language_servers: [typescript]` 后 `/mcp` → serena → reconnect |
| 引用查找只出同文件结果或返回 `{}` | jsconfig.json 丢失 | 恢复根目录 jsconfig.json（tsserver 文件监听即时生效，无需重启） |
| 需要详细报错 | — | 日志在 `~/.serena/logs/<日期>/mcp_*.txt` |

### 备注

- `jsconfig.json` 纯编辑器/LSP 用途，浏览器忽略，不影响"零依赖打开即玩"；**勿删**。
- 坑：project.yml 在首次激活时若检测不到二进制，会把 `language_servers: []` **持久化**——之后装包、重启会话都无效，必须手改该文件再重连。
- `.workbuddy/`（旧 story 备份）已在 jsconfig 排除，避免其 29 处过期调用污染引用/重命名结果。
