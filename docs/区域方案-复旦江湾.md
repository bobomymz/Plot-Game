## 时间预算与过夜（⚠️ 本方案对蓝本的核心修正）

**事实：** `isNight = hh >= 19`（core.js:341），全局触发器 priority 5 强制跳"天黑必须过夜"（core.js:543）。
**夜晚剧情.js 无 `currentArea == "复旦"` 分支** → 复旦章内天黑会落进"街头兜底"（第 234 行兜底未排除复旦）→ 玩家被传回初始小区，章节断裂。这是硬红线。

**蓝本 hh<16 上车门槛的时间数学（不够）：**
```
15:59 上车 → 16:29 到江湾 → 江湾探索 40-60min → 17:10-17:30 出发返程
→ 17:40-18:00 到家侧 → 楼道高潮+家中 45min → 18:25-18:45
→ 回建平-校园门口 ≈ 19:00 —— 贴线；磨蹭一点的玩家在楼道高潮中被打断
```

**方案（双保险）：**
1. 上车门槛收紧为 **hh < 14**（蓝本 hh<16 的再加严；错过的玩家建平宿舍过夜后次日上午再上车，窗口每日重现，无新增状态）。
2. 夜晚剧情.js 补**防御性复旦分支**（兜底排除列表 + 一个"车里将就一夜，次日清晨继续章节"节点）——把作者否决的"车里过夜"降级为极端磨蹭玩家的兜底保险，正常路径不可达。防的是 305 反复进出刷时间这类边角。

**章节耗时：** 约半个游戏日（车程 30×2 + 江湾 1-1.5h + 家侧 45min）。玩家第几天能到：建平为北线中后期，现实 Day 3-5，上车窗口看建平侧进度。

## 已拍板（2026-09-24 作者确认）

1. **药丸选项挂点 = 整理整理，无任何提示**（纯藏阴险：③结算 text 不提药丸；不开背包的玩家静默失去忻老师，延迟引信在物理办公室引爆，后悔滞尾到账）。软信号只有待定4拍板的"彭奕宸知情"（他离物理办公室最近，_xinTurned 后电脑区/高三14班补一句异样）。
2. **错过上车窗口 = 次日清晨独自离开**（章节 missable）。机制：首次具备上车资格时记 `_xinOfferDay`（hh<14 时 = 当天，否则 = 次日——首个"完整上午窗口"），`dd > _xinOfferDay && !_teacherLeft` → `_xinGone`。后门辅路空车位文案（碎玻璃上一道轮胎印）；物理办公室补空屋分支；他走前明说"明天上午等你，过午我自己走"，missable 有预告、不冤。
3. **卧室门"开门"贪心结局不做**：门只能看不能开，纸条即终章，家侧纯剧情。
4. **b 链不加原机共鸣 flavor**：纯功能，妈妈线情绪留给全家与未来回收点。
5. **a 链双窗口 + 忻老师江湾当日挂彩**（2026-09-24 追加，《腐烂尸城》大叔线同构；a 链机制保持二元 `_xinKnowsTruth`）：
   - **受伤时点 = 江湾当日**（环境楼门厅上楼时暗处贴墙一只，他护玩家、隔袖在小臂挂彩，浅伤；玩家半目睹，他一言不发）。mercury 数学（core.js 核实：抓伤+10、每小时+1、≥70 触发"结局-汞中毒尸变"）锁死更早的时点——章节前旧伤会把③深伤当场爆表、④余量也撑不住，全分支塌方。
   - **透露点 = 返程车程**（travelScene 改常驻场景，必经单程节点）：text 分段三级——报地址（b 窗口开）→ 等堵死的路口时卷袖透露（大叔线逻辑：你已决定陪他回家，他欠同行者一句实话，且"到我家属门口之前你必须知道跟的是什么"）→ 三态文案：a₁ 已给=平静版"按那姑娘的数据，我还有时间"；!a 有手机=绝望版交待后事（"到了楼下你先走，钥匙你拿着"）+ a₂ 选项；!a 无手机=同绝望版，只剩空口安慰。
   - **a₂ 与 a₁ 差异化**：a₁=主动·情报·双刃齐下（她的办公室/白天/遗物中间，点燃救家 urgency）；a₂=反应式·赦免（他刚给自己判完死刑，出示="你不是死刑"；水的那半在这里=「他们也还来得及」而非「他们正在被毒」；舞台=暮色车厢/手机屏光打在他脸上/卷起的袖口在两人之间）。门控 `!_xinKnowsTruth && hasWangPhone && wangPhoneBattery >= 6`，出示同 set `_xinKnowsTruth`，**不扣电**（见下"电量惯例"），窗口进家中（2×2 路由）前关闭。
   - **空口安慰陷阱**（有无手机都可见）：『被抓不一定会变的，我就是带着伤活下来的』→ 他摇头"电影里不是这么演的。……你们小孩命硬"，什么都不变——教玩家"只有一张说话的脸+确凿数字能动他"。
   - **①②动机支柱**：他早在江湾就自认"是个死人了"——堵门=死人买活人的时间，门缝塞进来的钥匙是遗产不是逃生指令。①②正文按此基调写。
   - **④ 同③口径**：药丸入口扩大到③④（`_xinOutcome >= 3 && _xinScratched`），④不给药同样挂 `_xinTurned` 延迟引信——最好的分支也藏着毒，与已拍板#1的阴险品味一致，且世界规则自洽（抓伤=倒计时，不分分支）。③=救命紧迫，④=积德从容，同一颗药丸两种分量。
   - **电量惯例（2026-09-24 核查仁济侧代码后对齐）**：王知筠手机电量是**门槛不是货币**——捡起按天衰减（`15-(dd-3)×3`，钳 0–15，仁济南院.js:1013）、充电器 set 15（需 `hasCharger`，检验科/整理整理两处充）、**全库没有任何按次扣电**（播放视频也只设 `>= 6` 门槛，不实际扣减）。a₁/a₂ 出示照此：门槛 `>= 6` 与视频同款（同义："电量够点亮屏幕给人看"），出示**不扣电**；"屏幕暗下去"之类的情绪节拍写进 text，不动变量。
