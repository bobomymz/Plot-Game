## 一、总体结构与动机链（布局A，已定稿）

核心：**江湾避难 + 救家人**。

```
建平后门 →[车程30min，杨浦全域沦陷]→ 江湾校区（本想落脚的"避难所"）
  ├ 环境科学楼305：王知筠不在了（她的线在此完结）
  ├ 找科学家要一个关于水的答案 → 得到的是空办公室 +（玩家携带的）死者的答案
  └ 尸潮随 dd 上涨（S20外环本周崩溃中，设计细节.md:713）
忻老师坐不住 → 家（建平附近小区，重闯走廊第二遍，难度高于去程）
  └ 高潮：楼道（原作式堵门/翻窗场景）
全部分支 → 建平-校园门口，免费获得忻老师的车
```

**他为什么要绕江湾（三重动机，缺一不可）：**
1. 他熟——建平物理老师 × **复旦招生办联络人**，每年组织学生来江湾研学；
2. 他要**答案**——传闻水有问题，妻儿在家喝了五天，找环境科学家确认"家里人还有没有救"；
3. 把你（他的学生）安置在"有科学家、有围墙"的地方，他再回家。

**研学三角（canon 焊点）：** 招生联络人组织研学 → 拉科普作者王知筠（B站频道、科协成员）给高中生讲过一堂课/参观过实验室 → 玩家当时就站在305里听她讲蚯蚓。占位场景里"研学来过的地方。你还记得吧？"由此获得实体。这是全库少有的合规"玩家本人危机前记忆"（个人记忆 pickup）落点。

**地理/沦陷依据：** 杨浦 Day 1 起全域沦陷（设计细节.md:797-803，黄浦江下游倒灌首批爆发区）；江湾校区在宝山/杨浦交界、距黄浦江约1km。现实格局：草地+小路+学院楼，地盘不大，主要是研究生——**这决定了区域规模：小而密，主室内只有环境科学楼，微电子/材料楼仅做外观印象**。

**已否决的布局B**（家在新江湾城、帮手=新造NPC"王知筠的研究生"+采样车）：理由——现有NPC联动更好（师生回路）、江湾之行动机更硬、305得以保持"无人的安静办公室"（人物档案.md:812-822 原定位）。

## 二、两个剧情旋钮

### a. 忻老师知道真相吗（在305定死，不到绝境才做）

- 他**顽固**：丧尸电影常识派，认为"被抓=感染=几小时内变"。空口转述、纸面记录（实验记录本）都动摇不了他——**只认王知筠的手机**，要让他亲眼看到里面的视频/数据（一张说话的脸 + 确凿数字）。
- **真相内容是双刃的**：告诉他"水有毒"，既救他（他的抓伤不是死刑），也判他家人死刑（他们喝了五天）。说与不说、说哪半，都是玩家的选择。
- 机制依据（已存在的汞系统，core.js）：mercuryLoad 0–100 隐藏变量，抓伤 +10、之后每小时 +1（mercury-chronic），**≥70 触发全局结局"汞中毒尸变"**（core.js:540）；tier2 起痛觉消失、瞳孔散大永久暗适应。玩家自己带着抓伤活着走完全图，就是"抓伤可扛"的世界内先例。
- **手机没电 = a 不可能**（wangPhoneBattery 按 dd 计算，充电走 hasCharger 那条线）。这是知识的维护成本，天生公平，**记为设计意图，勿当 bug 修**。

### b. 学生们来帮忙吗

- **只认玩家自己的手机**（全家门口的妈妈遗物原机）——它才有同学微信。华为展示机（新达汇拾取，桌面只有一个美团APP，新达汇.js:933）和王知筠的手机都不算数。
- 出场帮手：**蔡镜晓 + 彭奕宸**（骑自行车从建平出发）。**刘冠宇腿伤不出场**，但给一句电话里的戏（"我腿就不去了，蔡镜晓他们俩出发了"）。
- **叫人窗口**：从知道他家地址（305之后/车上）到**楼道口之前**，一次性，过点不候。门控：玩家原机 && phoneBattery > 0，通话 -5 电量。
- 前提设施：**忻老师家小区必须从建平步行可达**，且在建平正常游玩时期就能路过——用守卫语法拦住深入（锁着的铁门/空岗亭），仅留印象；章节开启后同一节点解锁深入。既是伏笔（先路过一次，章节里再见），也满足"学生骑车能到"的地理逻辑。

## 三、2×2 分支矩阵

| | !b（没叫学生） | b（叫了学生） |
|---|---|---|
| **!a**（没让他信真相） | ① 原作剧情 | ② 学生迟到 |
| **a**（305出示手机） | ③ 带伤双逃 + 药丸抉择 | ④ 学生救场，全歼 |

**全分支共同收束**：玩家回到 **建平-校园门口**（场景已存在，建平中学.js:241），**免费获得忻老师的车**（hasCar = true）。

- **① !a !b（原作剧情）**：家中变故 → 尸潮涌上楼道 → 他堵门，你翻窗。**堵门前把车钥匙从门缝里塞给你**（原作式手势，解决"车在楼下怎么到手"）。玩家独驾回建平。
- **② !a b（学生迟到）**：学生赶到时晚了，他仍牺牲（学生们目击老师的死）。钥匙交接同①。玩家带学生回建平。
- **③ a !b（带伤双逃）**：两人一起翻窗逃出，**均负伤**——玩家挂 hurtByZombie + mercuryLoad +10；忻老师伤得更重（**逃出时多处深抓伤**，这是"1天后尸变"的 in-world 依据：远超浅抓伤+10/2.5天的常轨，见下）。到校园门口后，**整理整理里出现"把无标签药丸给忻老师吃"选项**（背包界面即道德清单）。
- **④ a b（学生救场）**：两人多撑一会儿，蔡镜晓/彭奕宸赶到，四人合力击杀全部丧尸。无人受伤，玩家照常走闪色战斗节点 + combatDrain 扣体力（无人受伤≠无消耗，勿做成播片）。忻老师决定此后在建平避难。
- ③④ 他活着交车，一句台词兜住逻辑："你比我需要它，我留在学校了。"

## 四、③分支专项：药丸与延迟引信

- **药丸不新造**：`hasMercuryPill`（甲基汞抑制剂·童涵春堂无标签药丸）已存在——金谊广场童涵春堂拾取，玩家自用 mercuryLoad -20（core.js:159/1354）。
- **给出的条件**：分支③状态下、玩家在校园门口、hasMercuryPill、未给过。知识门控只管提示文本：带王知筠遗物的人知道它为什么可能有用；不知道的人是拿自己的救命药在赌（玩家自己多半也被抓过，全图 +10 节点二十余处——这颗药本来就是玩家的底牌）。
- **给了**：他的负荷被 -20 拽回阈值之下，活下来；后日谈对齐④（在建平安顿，物理办公室），只是没有学生救场的英勇版本。
- **不给**：**1天后尸变**。新增 `_xinTurned` 延迟引信：此后玩家进入"建平-远翔楼-3F-物理办公室"= 被咬死结局（场景已有 `_xinDead` 状态分支语法，照挂即可）。后悔滞尾到账。
- 结局节点建议专属立绘（如"结局-变了的忻老师"），命名遵守 `grep "结局-` 的归一惯例；章节内其他 QTE 失败复用共享死亡结局（自动获得耐久判定，武器耐久规范3）。
- **公平性**：漏捡/已用掉药丸的玩家，照退烧药双入口先例（设计细节.md:1006）在**仁济门诊药房放第二入口**（`!hasMercuryPill` 守卫，用掉后可回取）。
