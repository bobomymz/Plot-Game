# 区域方案：新达汇B1地下车库改造（车辆解锁重做）

> 2026-10-01 波波提出粗案，本文=细化+补充。原案五点：① 车辆解锁大改为直接获得车
> （幸存者从金谊广场开车来新达汇搬物资，下车被袭身亡）；② 障碍=Day3 时间门槛 + 车旁战斗
> + 必须先接线通电才能注意到这辆车 + 噪音引尸 + 任意区域随机搜车；③ 地图树状→网状；
> ④ 线索=车辙（只在图中标出，文本不提）/ 金谊长廊幸存者情报 / 入口地库平面图 / Day3+ 断杆。
> 诊断：原版车库"绕迷宫碰运气找到钥匙"，线索不导航、威胁不闭环、空间不可读，且全库无一处
> 提示指向车库。改造核心：**把"找钥匙"换成"接手一辆刚死之人留下的车"，把探索改成侦查。**

## 设计目标

1. 体验曲线完整：侦查（图/情报/车辙）→ 准备（通电）→ 遭遇（车旁战斗）→ 交割（搜身+上车）→ 爆发（点火逃亡）。不再是"挨个开车门"。
2. 时间成为关卡：Day1/2 车库=可探索的支线区（搜刮/涂鸦/可提前接线）；Day3 起才出现主线目标——**提前探索=提前投资，Day3 回访=收获**。
3. 信息=杠杆：平面图（配电室位置）、通电（车辙可见）、长廊情报（认出这辆车）三层信息各买一段效率。
4. 噪音经济有牙：随机搜车出声、ops 计数、点火=全场苏醒，形成"搜得越多、离场越险"的自举压力。
5. 涂鸦伏笔总兑现：「它们会从排水沟爬上来」——杀幸存者的就是它们，点火后全场涌上来的还是它们。

## 背景时间线（新增设定）

- **Day1–2**：车库维持原状（无目标车）。涂鸦、假线索车、可随机搜车、可提前接线通电。
- **Day3 晨**：金谊广场长廊的幸存者（身份待拍板，见§待拍板1）开车从辅路坡道闯入地库
  （撞断出口栏杆），往深处开到 F 区角落停靠，卸货时被从排水沟上来的丧尸袭击身亡。
  钥匙留在点火器上（刚停好车就出事）。
- **Day3+**：车、尸体、杀手丧尸都在 F 区；车辙（图）从坡道口一路延伸到 F 区；
  出口栏杆断成两截；尸体新鲜（0–2 天档：血腥汗酸，地库通风差气味更冲——按气味铁律）。
- **拿车动线**：战斗胜利 → 搜身（环境叙事+物资）→ 上车 → 点火（引擎声=全场信号）→
  QTE 冲坡道 → 撞开残杆出库 → `hasCar=true`。杆子已断=出库无障碍（断杆的双重叙事功能：物证+出口伏笔）。

## 主链定级

- **主链「把车开走」**：奖励=离开东明街道的载具，T1，≥5 杠杆
  —— 时间(dd≥3) + 前置操作(配电室接线) + 战斗(车旁闪色战) + 信息(平面图/长廊情报，非硬性) + 不可逆(车开走后不回) + 噪音清算(点火QTE)。
- **支链「提前探索」**(Day1/2)：奖励=物资(`_garageLootLeft`) + 提前通电 + 涂鸦情报，降低 Day3 的当日成本。
- **支链「随机搜车」**：奖励=散落物资，代价=ops/追兵/惊吓——莽夫流的补给来源，也是他们的死因来源。
- **错位点**：载具信息载体错位——不是"找到钥匙"，是"认出这辆车"（通电后车辙+没落灰）。

## 随机搜车系统（新玩法核心）

「搜查周围的车」入口挂在 A/B/D/E/G/F 各区（C 配电室无车位）。**判定顺序**：

1. `dd>=3 && _wiredCorrectly && 当前=F区` → **确定性入口**：目标车（车辙尽头、没落灰、驾驶座门虚掩）。
2. 否则（不在 F 区 / 未通电 / Day1-2）→ 加权随机池（函数式 nextScene `Math.random()`，先例：接线 30%）：

| 结果 | 权重(基准) | 内容 | 修正 |
|---|---|---|---|
| 空车 | 35% | 落灰、锁死，只看一眼车型 | — |
| 物资 | 20% | 水/口粮/小工具，`_garageLootLeft>0` 门控（世界库存型，拿完即空） | 通电/手电 +10% |
| 出声 | 25% | 拉门哐当/倒杂物 → `+1 _garageOps` 或 `+1 chasedByZombies` | 通电/手电 −10% |
| 车里锁着丧尸 | 15% | 拉门的瞬间里面一张脸 → 惊吓+小战斗或逃跑（复用现有后备箱惊吓骨架） | `chasedByZombies` 高时 +10% |
| 特别事件 | 5% | 一箱矿泉水 / 急救包 / Day3+ 的 F 区「没落灰的车」摸黑遭遇 | — |

- 防刷三闸：`_garageLootLeft`（初始值待拍板6）+ 每次 +1 ops + 驱逐不清零。
- ⚠ 随机结果在 onEnter 里 set 临时变量再渲染文本，避免同次停留文本/结果不一致；
  随机 nextScene 在回溯/读档后重掷——既有行为，可接受。

## 与既有机制的融合

- **`_wiredCorrectly` 接线**：保留并升级为硬前置。手电=看清图纸必成；无手电=乱接 RNG
  （失败=火花+噪音+ops，可重试，不直接死）。Day1/2 可提前完成，Day3 直接受益。
- **⚠⚠ `_powerOut` 硬冲突（必须处理）**：现状=玩家在 B1 保安室主动拉总闸（甩变异猫）后，
  `接线成功` 场景判 `_powerOut` → 永远亮不了灯 → **目标车永远找不到 → 卡死主线**。
  建议：**地库照明走配电室独立回路**（现实合理：车库防火分区独立供电），删掉该短路分支；
  拉过闸的玩家接线时文案反转为确认彩蛋："商场总闸管不到这片——车库有自己的回路，灯一盏接一盏地亮了。"
  需微调拉闸场景"整个地下层沉进黑里"的措辞（限指商场 B1 层）。待拍板2。
- **`_garageOps` 驱赶**：语义升级为"噪音水平"。≥3 水声警告保留；≥5 驱逐保留但**不清零**（隔天 -2）——
  上轮诊断的"驱逐=白板重刷"漏洞顺手修掉。待拍板4。
- **涂鸦伏笔**：Day1/2=环境怪话 → Day3+=WARNING → 点火逃亡=总兑现（全场排水沟涌出）。
- **E 区白荣威（假线索）**：保留，用 H 区杂物堆的撬棍+保养单讲圆来历。
- **G 区面包车**：保留为随机池素材（翻箱=噪音，现有骨架复用）。
- **王老师钥匙线**：整条保留不动（`hasCarKey` 唯一来源）。三林路丰田保留为该线的车；
  「查看旁边那辆轿车」加 `showCondition: "!hasCar"`（已有车不再提示）。
- **F 区拿钥匙节点**（`新达汇-B1停车场-拿钥匙`/`-没钥匙`）：删除，被事故点链取代。
- **`hasCar` 交割**：复用 `三林路-获得一辆轿车` 的 onEnter 骨架（`set hasCar` + 放弃电瓶车/自行车），
  出库后辅路/跨区旅行文案按 `hasCar` 分支（车停在辅路）。

## 已核实的机制事实（实现依据）

- `dd` 初始 1（core.js:12），Day3 = `dd>=3`；场景 text/choices 函数内可读。
- `_powerOut` 由玩家主动触发（`新达汇-B1保安室-拉闸`，新达汇.js:420–421），非脚本事件；
  现行 `接线成功` 的 `_powerOut` 短路分支即冲突点（新达汇地下车库.js:104）。
- 金谊长廊据点有门禁：食物换通行 / 被抢过则关死（金谊广场.js:206–223）→ 情报必须挂备用信源；
  3F 小林无门禁，其对话分支模板=函数式 choices + `_visit` 一次性（金谊广场.js:1081–1092）。
- "老周"=长廊头领（奥乐齐仓库主管，金谊广场.js:1100），**开车人不能叫老周**。
- 闪色战斗三档路由 `flashCombatRouter(胜,伤,死)` 及惩罚工厂均在 utils.js，路由闭包挂 `__sceneRefs` 供 lint 补入边。
