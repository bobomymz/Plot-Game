# 区域方案：11号线三林东路站改造（难度重做）

> 2026-10-01 批准。诊断：原版存在零风险免费通道（观察→员工通道→爬X光机→沿墙摸→上车），
> 漏斗结构无锁无奖励，strength>=2 守卫对初始体力7的玩家不可达，QTE 已被软化到 12/9/7/6s。
> 改造核心：**难度从反应力移到决策与准备**——堵免费通道、给噪声经济装牙、发车不可逆。

## 设计目标

1. 首刷不可能一遍通关，但每条死路都指明下一步该准备什么（死因可读）。
2. 信息/准备度成为通关货币：侦查流可用零战斗换通关。
3. `chasedByZombies` 在本区有清算点（隧道尸潮 + QTE 大幅缩短）。
4. 奖励给足理由：钥匙串（跳过两层战斗）、站务室（T0 情报 + 物资）、发车（进入好结局）。

## 主链定级

- **主链「让列车动起来」**：奖励=区域进度（迪士尼幸存者聚居地好结局），T1，≥2 杠杆
  ——前置物品(钥匙串) + 战斗(搜尸/缠斗 QTE) + 多步(配电间合闸) + 信息(用电规程) + 状态(强黑暗) + 不可逆(发车)
- **支链「站务室」**：奖励=6/28 监控情报(T0) + 用电规程(信息) + 应急物资(T1)
- **错位点**：电力门槛首次实装（套路清单"银行金库已伏笔未实装"项）；钥匙信息载体错位（从死人腰间取，不是找钥匙）。

## 守卫表

| 连接 | 守卫 | 意图 |
|---|---|---|
| 观察 → 搜尸/缠斗 | QTE 5s / 缠斗选项内嵌力≥2 | 先观察者得钥匙情报 |
| 员工通道铁门 | `hasMetroTools` 开门(showCondition)；"撞门"常驻软门槛 | 钥匙第一用途：跳过两层战斗 |
| 摸黑路线 | `!hasTorch && !hasFireTorch && !_stationPowered` 时站台选项收窄 | 强黑暗只认手电/火把（建平工具间先例），不硬锁 |
| 隧道尸潮 | 进站台的选项带 `condition: "chasedByZombies < 4"` + elseScene | 噪声清算点 |
| 配电间闸刀 | 入口在铁门后；顺序对错由 `_procedureKnown` 决定文案走向 | 无情报=试错赌噪音（软） |
| 发车确认 | 无守卫，纯确认+不可逆警告文案 | 删随时"下车退回地面"的软脚 |
| 合闸 → 站台 | `set: _stationPowered`，站台 text/条件随它切换 | 侦查流连手电都省（奖励闭环） |

## 路线推演（难度验证）

- **侦查流**：观察→水瓶引开→搜尸→员工通道→站务室(规程+物资+监控)→配电间一次合对→员工梯(站台已亮)→潜行→发车。零战斗零手电，吃 2 个 QTE+大量时间。
- **莽夫流（首刷落点）**：快步→硬冲→踹飞→站台没电没灯→摸黑赌命或发现死火折返（楼梯已变样）→补钥匙走员工线。噪音堆到 3-4 触发隧道尸潮。
- **折中流**：有手电无钥匙→站台看得见但车死火→折返。纯跑腿段仅 1（员工梯走廊），折返段有新内容。

## 结算清单

- 新增节点 12：站厅-观察改版 / 搜尸 / 缠斗 / 铁门 / 走廊 / 站务室 / 配电间 / 员工梯 / 楼梯-折返 / 摸黑 / 隧道尸潮 / 发车确认；改写迪士尼门口为好结局。
- 新增死亡结局 3：搜尸失手（尸体攥腕，它没死透）/ 摸黑坠落轨道 / 隧道尸潮围堵。原 4 个保留。
- 新增占包 1：钥匙串 `hasMetroTools`（+itemCount 1）。复用：`hasBottle`/`hasBiscuit`（站务室，`!hasX` 守卫）、灭火器 flag、手电/火把。
- 新变量（core.js `_variables`）：`hasMetroTools` / `_stationPowered` / `_procedureKnown`。
- QTE 恢复：8s→6s→4s→3s，表达式 `Math.max(2000, N000 - chasedByZombies * 800)`（引擎 `new Function` 求值，全局 Math 可用）。

## 已核实的机制事实（实现依据）

- QTE timeout 字符串经 `new Function(...keys)` 求值，`Math.max` 可用；引擎对负值有兜底。
- 无场景级 redirect：隧道尸潮分流必须写在**进站台的来源选项**上（condition+elseScene）。
- 强黑暗守卫先例：建平工具间 `vars.hasFireTorch || vars.hasTorch` 分支 text/choices。
- `updateTime(N)` 单位=分钟，雨天×1.3；室内场景不吃户外疲劳。
- choices 支持 `function(vars)` 返回数组（建平先例）。

## 已知遗留（本方案不做，记录在案）

1. 夜晚剧情.js「天黑必须过夜」无地铁站分支——深夜困在站内的玩家会落到通用室外文案。后续可加 `currentPos == "地铁站"` 分支（站务室=安全屋）。
2. 楼梯层正文写死"被水冲散的丧尸追上来"——与灭火器/绕路路线轻微不耦合，改版文案已做中性化。
3. 迪士尼好结局为占位（"幸存者聚居地"），后续做正片时替换。
