# Proposal

## Why

游戏中存在一类"文档/物品特写"场景图（工牌、手机、地图、A4 纸等竖构图），现有渲染对它们两头不友好：桌面端 `object-fit: cover` 会把竖图裁成中间一横条，手机端 `contain` 又把它们缩成难以辨认的邮票。这类图恰恰是最值得玩家细看内容（纸上文字、屏幕信息）的图，需要一个微信式的点击查看器让玩家能完整查看并局部放大。

## What Changes

- 新增场景数据字段 `imageZoom: true`（布尔，缺省无）：声明该场景图可点开查看器。角标 = 门票——只有带标记的场景图响应点击放大，未标记的图点击无反应。
- 带标记场景的图片区角落显示 🔍 角标，作为唯一可点信号；桌面端附加 `cursor: zoom-in`。
- 新增图片查看器（engine.js + style.css）：
  - 点击标记场景图 → fixed 深色背板全屏打开，图片 contain 完整居中（永不裁切）
  - 桌面滚轮缩放（以光标为中心）、手机双指捏合缩放；范围 = 适配屏 ~ 4×；放大后可拖拽平移
  - 单击/点按、Esc 关闭；移动超阈值算拖拽、不触发关闭
  - 换场景/回溯/重启/死亡自动关闭；记忆闪色启动时自动关闭
  - QTE 倒计时不暂停，QTE 条（z-150）浮在查看器（z-140）之上始终可见
- 查看器为纯 UI 态：不进 `gameState`、不进存档，读档恢复后查看器为关闭状态。
- 教程：初始卧室场景加 `imageZoom: true`，首访文本末尾沿用现有灰色小字惯例补一句教学（"带 🔍 的场景图可以点开细看"）。
- 首批内容迁移：利昂的工牌、库房的手机、高锦睿给的地图三张文档图所在场景挂上 `imageZoom`。
- 文档同步：CLAUDE.md（数据格式节、z-index 表、查表）、手机端适配.md。
- 明确不做：早期 0.75 比例场景图（文具店/服装店/五金店等）的重新生成，由作者另行处理，不属于本变更。

## Capabilities

### New Capabilities

- `image-viewer`: 标记门控的图片放大查看器——场景字段声明、角标提示、打开/缩放/平移/关闭交互、与 QTE/记忆闪色/场景切换的协同规则。

### Modified Capabilities

（无——项目尚无既有 specs。）

## Impact

- **代码**：`engine.js`（查看器打开/关闭/缩放/平移、点击绑定、场景切换与闪色的自动关闭钩子）、`style.css`（查看器覆盖层、角标、cursor）、`story/东明街道/樱桃苑（初始小区）.js`（初始卧室标记 + 教学文案）、三个文档特写场景所在 story 文件（挂标记）。
- **数据格式**：新增可选场景字段 `imageZoom`，向后兼容，缺省不改变任何现有场景行为。
- **z-index 体系**：查看器占用 140 层（文本展开 101 之上、QTE 条 150 之下），需更新 CLAUDE.md 层叠顺序表。
- **依赖**：无新增外部依赖（纯原生 JS/CSS，Pointer Events 统一鼠标与触屏）。
